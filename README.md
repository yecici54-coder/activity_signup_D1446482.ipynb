## 三、問題回答

### 問題一
測試一中，桌遊整理後的串列 `['amy', 'ben', 'amy', 'cora']` 有 4 筆資料，但桌遊費用應以 **3 人** 計算，因為規則規定同一人在同一場活動重複出現只算一位參加者、只收一次該場費用；串列中的 `'amy'` 出現兩次屬於重複報名，去重後實際參加桌遊的人只有 `amy`、`ben`、`cora` 共 3 人，因此桌遊應收為 `3 × 120 = 360.00` 元。

直接把字串拆成 `list`，**保留了**原始報名的先後順序與重複次數；**失去了**自動去重與集合運算的特性。再轉成 `set` 之後，**保留了**不重複的參加者成員，方便做交集、聯集與差集比較；但**失去了**原本的先後順序與重複出現的次數。

### 問題二
測試三中，桌遊去重名單為 `{'amy', 'ben', 'cora'}`（3 人），電影去重名單經大小寫與空白清理後同樣為 `{'amy', 'ben', 'cora'}`（3 人）。

- **集合關係**：桌遊集合 $B$ 與電影集合 $M$ 相同，因此交集 $B \cap M = \{\text{amy}, \text{ben}, \text{cora}\}$（共同人數 3 人），聯集 $B \cup M = \{\text{amy}, \text{ben}, \text{cora}\}$（總不重複人數 3 人），兩個差集 $B - M$ 與 $M - B$ 皆為空集合（顯示為 `[]`）。
- **人次與費用算式**：報名人次是兩場各自去重人數相加，因為這 3 人兩場都參加，每人各算 1 次桌遊與 1 次電影，所以報名人次為 $3 + 3 = 6$ 人次；各場分別計費後，總應收為 $(3 \times 120) + (3 \times 80) = 360 + 240 = 600.00$ 元。
